# 📱 Phone Usage Analytics - Lớp 9B (Dark & Blue Theme)

Hệ thống Mini App khảo sát và phân tích thời gian sử dụng điện thoại và giấc ngủ của 30 học sinh lớp 9B.

## 🌟 Tính năng nổi bật
- **Giao diện:** Dark & Blue Theme hiện đại, dịu mắt.
- **Bảo mật:** Hoàn toàn ẩn tên học sinh (chỉ hiển thị Mã học sinh `HS01`, `HS02`...).
- **Tính toán:** Ánh xạ 100% công thức Excel nâng cao (`COUNTIF`, `SUMIF`, `IF`, `MOD`).
- **Triển khai:** Tương thích với Streamlit Cloud và GitHub Pages (chi phí 0đ).

## 🚀 Hướng dẫn chạy cục bộ (Local)
```bash
pip install -r requirements.txt
streamlit run app.py
